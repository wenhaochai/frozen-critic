# Frozen critic, random actor: brief (from the terminal session, 2026-10-05)

## The question

Can an actor trained **from random initialization** learn to solve math (GSM8K first) with PPO when its only
dense signal is a **frozen, already-trained critic** (value model)? The owner's hypothesis: "next-token
prediction is mainly good value pretraining; the actor has to be learned from scratch." This experiment tests
the second half directly: value given and frozen, policy learned from nothing.

## Setup the owner fixed (2026-10-04/05)

- **Critic**: `paradigma-inc/limite-1b-value-model` (Hugging Face, released 2026-09-21), frozen for the whole
  run. 1.035B params, custom "GMPT" backbone + scalar value head, Qwen vocabulary (ids 0–151666). It returns one
  *pre-action* value per response token, V(prompt, response[:t]), regressed on binary final-correctness returns
  (gamma 1, critic lambda 1) during an earlier online actor–critic run. Values are raw regression scores, not
  calibrated probabilities. Read its README and MODEL_DETAILS (token alignment: pre-action = post[:, P-1:P+L-1];
  off-by-one warning; eager backend ≤4096 tokens; FA2/FA3 builds; one unpadded sequence per call, no batching).
- **Actor**: randomly initialized, Qwen tokenizer/architecture (start with a Qwen2.5-0.5B or 1.5B *config* with
  random weights), the only trained model. Actor and critic may be heterogeneous.
- **Algorithm**: PPO with GAE in **miles**. Arms: lambda ∈ {0.95, 0.5, 0}. The owner dropped the GRPO
  (outcome-only) arm and the lambda = 1 arm (critic as baseline only): do not run them.
- **Task**: GSM8K. Not AIME.

## Background

- Literature review done in the terminal session (summary page, written for an earlier framing with a pretrained
  actor; the random-actor framing above supersedes it): https://claude.ai/artifact/BczqKoEiX6gqN8mMTYScYt
  Main points for this framing: RLVR mostly elicits what a pretrained policy has (Yue 2504.13837, Echo Chamber
  2504.07912); text RL from scratch without MLE warm start failed historically (SeqGAN, "Language GANs falling
  short" 1811.02549); frozen scorers get hacked without the outcome reward (PURE 2504.15275, RFPO 2609.37119);
  closest frozen-critic work RFPO 2609.37119 and DVPO 2502.16944; non-language "LLM critic, policy from scratch":
  Motif 2310.00166.
- Expected difficulty: a random actor samples near-uniformly over ~151k tokens; the critic has never seen such
  prefixes, so its values may carry no gradient. If Phase 0 shows that, propose a reduced-vocabulary actor
  (digits, operators, a few words) mapped to text for the critic.
