# Frozen critic, random actor: status

**Phase 0 (2026-10-06):** the frozen Limite critic reproduces its card exactly and ranks other models' GSM8K solutions moderately (within-problem AUC 0.66-0.73 on Qwen2.5 generators, above a length baseline on the general ones), but it gives a random actor an almost flat signal (values 0.53-0.65, per-token change sd 0.033) that greedy token search cannot climb above a correct solution: hard to exploit, little to learn from.

**Phase 1 (2026-10-09), redesigned:** the full-vocabulary runs are dropped (owner: they do not make sense; a random actor over 151,667 tokens cannot sample a boxed answer, about 1e-30 per position). Character-level arm: 0.46B dense qwen3_5 actor, own 100-token vocabulary (1:1 to critic ids), ASCII prompts, output masked to 27 arithmetic ids, reward = strict grade + 0.1 format for a finished boxed number. Job 15264957 (lambda 0.95 and 0.5, 300 steps each, 12.0 + 11.9 H100-h): within 30 steps the actor stops ending responses (99% cut at 1,024), fills them with 'boxed', '\\' and '{' (83.6 'boxed' per response at lambda 0.95), test accuracy 0.0 at all 16 evals, no boxed-number finish after rollout 10, two lucky truncated one-digit boxes graded correct. Cause: at the stop token the advantage is r - V with the critic's V about 0.5 (a competent policy's success rate), while one more token costs about 0, at any lambda < 1. Lambda 0 not run (jobs cancelled). Grad probe 15251724: the step-0 grad norm 9.3e11 is entirely the input embedding's grad (word_embeddings); every other parameter is normal and identical at the next rollout, so the embedding grad buffer holds garbage at the first step only.

## Notes

- The critic API scores one sequence per call. `src/critic.py` packs many sequences into one row: positions restart
  at 0 per sequence and the backbone's boundary function is swapped for one that reads the restarts. Every other
  GMPT op is per token, so packing is exact up to bf16 kernel noise (2.5e-3 max on CPU eager).
- Critic token ids: Qwen2.5 ids plus `<think>` 151665 and `</think>` 151666; valid ids < 151,667. A random Qwen2.5
  actor has 151,936 embedding rows; rows >= 151,665 must be masked (0.18% of samples per token otherwise).
- Completed responses end with `<|endoftext|>` (151643) for the critic, whatever the generator's stop token.
