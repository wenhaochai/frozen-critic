# Frozen critic, random actor: status

**Phase 0 (2026-10-06):** the frozen Limite critic reproduces its card exactly and ranks other models' GSM8K solutions moderately (within-problem AUC 0.66-0.73 on Qwen2.5 generators, above a length baseline on the general ones), but it gives a random actor an almost flat signal (values 0.53-0.65, per-token change sd 0.033) that greedy token search cannot climb above a correct solution: hard to exploit, little to learn from.

**Phase 1, interim (2026-10-09; lambda 0.95 finished, 0.5 and 0 resuming):** PPO with the frozen critic did not teach a random actor GSM8K, and with a random actor no text-based reward can fire: the actor starts near uniform over 151,667 tokens (mean log prob -11.67 vs ln V = -11.93), and the shortest boxed number '\\ boxed { d }' + EOS is 6 specific tokens, about 1e-30 per position, so neither a correct answer nor a format reward is ever sampled (owner, 2026-10-09). The only signal is the critic's per-token values through GAE with lambda < 1, and under them stopping costs about -V = -0.6 at any lambda < 1, with or without the V(full) truncation bootstrap; responses stopped ending after rollout 47 (lambda 0.95), 21 (0.5) and 24 (0). Lambda 0.95 ran all 300 PPO steps (job 15202994): GSM8K test accuracy is 0.0 at all 16 greedy evaluations and none of the 153,600 training responses is correct, while the critic's value before the last token rises from 0.604 to 0.654. The actor fills every response to 1,024 tokens with tag tokens (`</think>`, `<think>`) and filler fragments; it never writes `\boxed`. Lambda 0.5 (to rollout 208, ckpt 199) and lambda 0 (to rollout 47, ckpt 39) show the same pattern so far. ## Notes

- The critic API scores one sequence per call. `src/critic.py` packs many sequences into one row: positions restart
  at 0 per sequence and the backbone's boundary function is swapped for one that reads the restarts. Every other
  GMPT op is per token, so packing is exact up to bf16 kernel noise (2.5e-3 max on CPU eager).
- Critic token ids: Qwen2.5 ids plus `<think>` 151665 and `</think>` 151666; valid ids < 151,667. A random Qwen2.5
  actor has 151,936 embedding rows; rows >= 151,665 must be masked (0.18% of samples per token otherwise).
- Completed responses end with `<|endoftext|>` (151643) for the critic, whatever the generator's stop token.
